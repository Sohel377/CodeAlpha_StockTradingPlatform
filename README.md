# CodeAlpha_StockTradingPlatform
Console-based Stock Trading Platform developed in Java using OOP concepts. Features include market data display, buy/sell operations, portfolio management, transaction tracking, and performance monitoring.

# Stock Trading Platform

## Overview
This project is a console-based Stock Trading Platform developed in Java as part of the CodeAlpha Internship Program.

The application simulates a basic stock trading environment where users can view market data, buy and sell stocks, track their portfolio, and monitor transaction history. The project is built using Object-Oriented Programming (OOP) concepts such as classes, objects, encapsulation, and collections.

## Features

- Display available stocks and market prices
- Buy stocks
- Sell stocks
- Portfolio management
- Transaction history tracking
- Portfolio value calculation
- Balance management
- Console-based user interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Scanner Class

## Available Stocks

- TCS
- INFY
- WIPRO
- HCL
- RELIANCE

## Project Structure

- Stock Class – Stores stock information
- User Class – Manages user balance and portfolio
- Transaction Class – Records buy and sell transactions
- Main Class – Handles menu operations and program flow

## Menu Options

1. Display Market Data
2. Buy Stock
3. Sell Stock
4. View Portfolio
5. Transaction History
6. Exit

## How to Run

1. Download or clone the repository.
2. Open the project in any Java IDE (IntelliJ IDEA, Eclipse, VS Code, etc.).
3. Compile and run the `StockTradingPlatform.java` file.
4. Use the menu options to interact with the platform.

## Sample Workflow

- View available stocks
- Buy shares of a stock
- Check portfolio details
- Sell shares when required
- View transaction history
- Monitor portfolio performance
